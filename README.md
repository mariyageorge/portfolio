# Mariya George — Portfolio

Built with React, Vite, Tailwind CSS.

## Quick start

```
npm install
npm run dev
```

## Edit content

Everything text-based (skills, projects, experience, links, email) lives in
one file: `src/data/portfolioData.js`. Edit that file and the whole site
updates — you don't need to touch the component files for content changes.

## Add your resume

Drop your PDF at `public/resume.pdf`. The Download Resume buttons already
point to that path.

## Add your LinkedIn

Open `src/data/portfolioData.js` and replace the `linkedin` placeholder URL
with your real profile URL.

## Build for production

```
npm run build
```

Output goes to `dist/`.
